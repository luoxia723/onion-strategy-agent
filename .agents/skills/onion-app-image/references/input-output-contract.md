# APP 图片生成输入、输出与人工门禁

## 输入

- 已确认图片文案及版本；
- 产品事实和品牌资产；
- 确定的制作配置：渠道、版位、形式、套数、Logo、IP、字体、CTA、UI、参考图角色；
- 真实 UI 截图（需要可识别界面时）；
- 候选数量与付费授权。

输入图片文案使用当前`onion-app-image-copy`固定字段：单图读取`主标题`、`副标题`，双图读取`短句1`、`短句2`，三图读取`短句1`、`短句2`、`短句3`。不要求旧版D-ID、C-ID或飞书记录ID。

## 人工门禁

1. 图片文案已确认；
2. 制作配置已保存；
3. UI 门禁已满足；
4. 候选数量与费用已确认；
5. 候选生成后由用户选择；
6. 只有采纳图片正式交付。

## 输出

```text
.runtime/策略Agent产物/<北京时间日期>/APP图片/<任务ID>/
├── 图片文案.md
├── image-config-result.json
├── image-render-manifest.json
├── image-render-result.json
├── 候选图片/
├── image-selection.html
├── image-selection-result.json
├── 图片质检.json
└── 交付图片/
```

任务重跑使用新版本，不覆盖已有候选和采纳图片。默认不生成 ZIP、不发布、不投放。

## 停止条件

- 文案未确认；
- 配置未形成确定结果；
- 产品事实或品牌资产缺失；
- 要展示真实 UI 但没有截图；
- 未授权付费；
- 候选文字、事实、规格或合规检查不通过；
- 用户尚未完成选择。
