# 压缩与导出

使用统一MCP的服务端图片交付处理完成尺寸和体积调整；`scripts/image_compress.py`只保留为维护工具。原图、候选图与采纳交付图分开保存。默认交付`04_交付`目录，不自动生成 ZIP；只有用户明确要求“打包”时才生成。

ZIP固定写入`06_打包/<业务线_功能方向>_APP图片_交付包_<版本>.zip`，相邻保存`..._交付清单.json`，ZIP内部也必须包含不带绝对路径的`交付清单.json`，逐文件记录相对路径、字节数和SHA-256。ZIP只包含采纳图片，不包含候选、缓存、临时URL或供应商凭据。

导出前检查：像素、比例、文件格式、色彩、文字可读性、Logo、UI、留白和平台体积上限。平台规格未确认时不声称“已适配”，只输出当前尺寸并标待确认。
