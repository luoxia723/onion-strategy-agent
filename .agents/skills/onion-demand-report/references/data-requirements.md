# 外部需求报告取数事实合同

## 1. 目标时间节点

正式取数前必须已有用户指定的目标时间节点。该节点是需求筛选条件，不是数据采集日期。

至少记录：

- 用户原始输入；
- 可解析的真实学习阶段或任务；
- 如用户给了明确日期，记录日期范围。

## 2. 当前外部采集批次

只使用本次冻结的当前采集批次，不使用内部报告周期推算外部范围，不补历史同节点证据。

批次至少取得：

- 批次 ID 或可唯一说明范围的批次身份；
- 实际采集起止日期（如有）；
- 平台和来源构成；
- 冻结时刻；
- 分页与 coverage 状态。

## 3. 外部证据

每条证据至少取得：

- 稳定证据 ID；
- 独立来源语境 ID；
- 来源类型：内容、评论或广告；
- 平台；
- 可回源标题和链接；
- 需求主体或表达视角；
- 具体人群；
- 学习/家庭任务和具体场景；
- 核心问题；
- 当前应对（可空）；
- 期待变化（可以是问题的最小反向表达）；
- 证据定位和数据完整度。

## 4. 守恒

正式报告必须能核对：

- 批次稳定证据总数；
- 独立来源语境总数；
- 内容、评论、广告数量；
- 实际进入目标时间节点需求分析的证据数；
- 范围外、信息不足、重复和排除数量。

同一证据可以支持多个真实需求，所以不同需求的证据数是非排他的，不得求和解释为批次唯一证据总数。
