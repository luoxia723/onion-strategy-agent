# 口播主轴混剪

> 业务状态：2026-08-26经xhh确认完成并冻结。冻结范围包括单一公共Skill、`business_line`参数化、母片与CTA校验、hybrid配画、计划合同和停止条件；除非xhh明确重新开启讨论，不再拆回APP/线索入口Skill，也不因某次素材不足或成片运行失败重做业务合同。

## 产物

以真人或数字人口播母片为正文主轴，生成一份同时包含业务线、母片、CTA、配画和渲染事实的混剪计划，以及字幕、最终 MP4 和质检结果。APP 与线索只是同一流程的输入参数，不产生独立入口 Skill 或入口记录。

## 必需输入

- 一个目标业务线：`app`或`lead`；
- 母片来源：素材库稳定母片或用户当前上传文件；
- 母片来源、哈希、真人/数字人类型、识别出的业务线、完整清洗文案及真实句级/词级时间轴；
- 结尾CTA文本、时间范围、类型、兼容判断和判断依据；
- 零或一条已存在前贴，或明确不使用；
- 逐语义段hybrid素材候选、稳定身份、源时间范围、检索证据和媒体文件；
- 版本数量与批量主体模式；
- 用户对 ASR、取源、渲染、上传暂存等外部/付费动作的当前授权。

素材母片事实、配画搜索、稳定ID回查、短时取源、任务媒体上传和渲染都使用统一 HTTP `onion-agent` OAuth MCP；不得读取旧本地索引、腾讯 COS 或直接对象存储。用户当前上传母片先调`generation_upload_media`变成短时`output_id`，不写入素材库。

## 固定流程

1. 用户没有给出目标业务线时只确认`app`或`lead`；不创建另一套工作流。
2. 素材库来源按目标业务线检索并以同一业务线回查；用户上传来源记录文件哈希、识别业务线和CTA。
3. 在本 Skill 内完成母片业务线与CTA兼容检查；出现相反业务线的明确CTA时停止，不靠画面覆盖或字幕掩盖原声冲突。
4. 冻结母片、原声、哈希、文案和真实时间轴；不改真人说话内容。批量生成时确认是“同一真人换配画”还是“多个真人分别制作”。
5. 确认零或一条前贴；如有，完整播放并保留原声，正文整体顺延。
6. 先规划必须保留真人的区间，再确定适合配画的产品动作、场景、证明或抽象概念。
7. 每个配画语义段固定使用`materials_search_segments(retrieval_mode=hybrid)`；从真实候选中终选并回查素材事实，没有合格候选时保留真人。
8. 多版本避开近期和本批重复素材，并对合理配画位置做有限差异；不能只换素材但复制完全相同的切点。
9. 生成并校验一份完整混剪计划；业务线、母片和CTA检查直接写入计划，不额外生成入口记录。配画静音，时间范围不重叠、不越界。
10. 将母片URL或已上传`output_id`、静音配画计划、真实字幕时间轴和可选的一条完整有声前贴映射到`generation_render_talking_head_video`；传当前任务授权和绑定计划哈希、母片哈希、版本的幂等Key。立即下载MP4与工具返回的ASS字幕产物，分别校验SHA-256，再完成自动技术检查和人工完整听看。
11. 交付本地计划、字幕、成片和 QA；不入库、不发布、不投放。

## 核心边界

- APP 与线索共用同一个 Skill；差异只体现在`business_line`、母片业务标签和CTA兼容判断。
- 素材库母片不得跨业务线复用。用户上传母片可以识别为未知，但必须完成目标业务线CTA检查。
- 真人或数字人原声和人物信任感是主轴，不能做成只有声音的纯配音视频。
- 开头、结尾和关键情绪段优先保留人物；配画只解决理解和证明。
- 前贴最多一条，必须已存在；本 Skill 不生成新前贴。
- 母片和转写/时间轴不一致时停止，不按字数估时。
- 配画只接受真实`hybrid`检索候选，不使用纯词法、本地旧索引或手写素材ID替代。
- 自动 QA 不能替代人工观看。
- 下游不需要ffmpeg、TOS、数据库或供应商Key；正式渲染由统一MCP的火山VOD异步剪辑Adapter执行，字幕作为云端文字轨压制。统一生成工具或VOD readiness缺失时停止。
