# 素材承接对象命名合同

## 1. 目的

内部需求归并保持产品中立，但报告中的产品、功能、服务和权益名称必须统一。命名归一只解决“这些原表达是否指向同一个对象、报告应显示什么标准名”，不判断当前是否仍有该能力，不审核素材承诺，也不建立需求—功能直接关系。

## 2. 权威来源

产品、功能、服务和权益标准名的唯一权威源是当前主仓库的[产品事实与卖点](../../../../产品资料/产品事实与卖点.md)。当前文件是 xhh 已确认可用的 2026-08-03 冻结快照，其源码 owner 为根目录 `产品资料/`。

`Skills/01_维护相关/onion-material-ingest/runtime/visual_annotation/references/功能词表.md` 只用于素材入库的功能画面标注，不是产品事实全集，不得作为本报告的承接标准名权威源。

## 3. 命名步骤

1. 从 AI-02 promoted_offering、说服路径和功能步骤中判断整条素材的主承接对象。
2. 与《产品事实与卖点》的“功能名称”、“卖点名称”和明确产品/服务名做语义匹配，不做原字符串精确匹配。
3. 只有唯一对应时才写产品事实文档中的标准名。
4. 品牌前缀、AI 前缀、“功能/服务”后缀、空格、大小写、括号和明显误写可以作为别名差异消解。
5. 无法唯一映射时只在数据层记录未归一状态，不写入报告的主要功能/服务承接，不自创标准功能名。
6. 待归一对象需由 xhh 确认是否补入产品事实、改名或保留为历史服务/权益。

## 4. 强制例子

| 历史原表达 | 报告标准名 |
|---|---|
| 洋葱拍题精学功能 | AI拍题精学 |
| 洋葱AI拍题精学 | AI拍题精学 |
| AI拍题精学功能 | AI拍题精学 |
| 洋葱学园AI定制班 | AI 定制班 |
| 洋葱AI私教动画课 | AI 私教动画课 |
| 无法与产品事实唯一对应的历史名 | 不进入报告承接字段 |

同一标准名下的历史原名、说服路径、利益、结果、证明、权益和 CTA 只是该对象的素材表达变体，不再生成新功能/服务承接。报告不展示原推广名或无法归一的历史原表达，这些事实只留在数据层和素材回源中。
