# 信息流短广告矩阵

信息流不是品牌 Slogan。每套只保留`一个具体卡点×一个产品动作×一个即时变化`，让孩子先认出自己的处境，再看懂产品怎么接住。

## 可用类型

常规角度直接来自选中方向：

- `场景`：时间、任务和卡住瞬间；
- `痛点`：当场阻碍或损失；
- `结果`：最先可观察的行为变化；
- `机制`：一个差异化产品动作；
- `对比`：旧/新做法或使用前/后；
- `时间`：为什么现在急、能少等哪一步；
- `身份`：学段或处境中的自我判断；
- `异议`：输入明确出现的真实顾虑。

`证据`、`数字`、`优惠`及竞品对比必须有对应正式事实片段，没有就不生成。

标题写法只有5种：`直述`、`提问`、`反差`、`如何`、`好奇`。提问必须由副标题接住；反差两侧都要真实；“如何”不能承诺结果；好奇必须点明具体对象，不能做空标题。

`文案类型`写成`广告角度×标题写法`。先判断有事实支持的角度，再选择不同组合；多条方向先覆盖不同卡点，同一方向再扩展。相同组合不能凑数，去掉形容词后仍是同一句话的候选只留更具体的一套。

主标题只承担一个 Hook，默认不写产品名；副标题写一个产品动作和一个当场变化，品牌识别优先放在副标题。两句不能同义复述。
