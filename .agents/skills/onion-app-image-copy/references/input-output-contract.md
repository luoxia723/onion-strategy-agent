# APP 图片文案固定合同

## 最小输入

- 用户选中的9列方向行及对应`方向依据`；方向依据必须给出本方向使用的产品动作/卖点和产品事实来源；
- 渠道与图片形式；
- 可选：数量、参考文案、风格偏好。

默认只读选中方向，不读同卡其他方向、完整产品事实、需求报告或创意报告。用户明确要求增加证据、数字或优惠时，只补充对应正式事实片段；没有片段就不生成。

## 合法形式

| 渠道 | 图片形式 | 文案字段 |
|---|---|---|
| 信息流 | 单图 | `主标题`、`副标题` |
| 学习机 | 单图 | `主标题`、`副标题` |
| 应用商店 | 单图 | `主标题`、`副标题` |
| 应用商店 | 双图 | `短句1`、`短句2` |
| 应用商店 | 三图 | `短句1`、`短句2`、`短句3` |

其他组合不生成。信息流固定面向孩子，只使用学生/孩子方向；家长可出现在场景中，但不能成为目标受众或叙述视角。只有家长方向时停止并请用户改选。

## 固定输出

文件级依次输出：

1. `# APP图片投放文案`；
2. `方向卡`；
3. `产品事实来源`，直接继承选中方向；
4. `本批文案数量`；
5. `人工状态：待审核`。

每套使用`## 文案 N｜自然标题`，依次输出：

1. `渠道`、`图片形式`、`文案类型`；
2. `目标人群`、`具体场景`、`产品动作`、`可感知变化`；
3. 与图片形式对应的文案字段；
4. `事实边界`。

信息流`文案类型`写为`广告角度×标题写法`，如`痛点×提问`。不属于当前图片形式的字段不输出。产物使用新版本，不覆盖旧稿；人工确认后才能进入图片生成。
