# 外部视频创意报告

## 目的

回答：本期外部完整视频案例中反复出现了哪些可迁移的创意关系，哪些只是单例探索，以及这些关系由哪些可回源案例支持。

正式产物是一份单文件 Markdown。完整案例留在数据层；报告只展示可消费结构、2至3条标准化代表案例和外部来源观察。

## 运行前读取

- 使用当前已部署数据工具时读取[HTTP MCP适配](../../references/http-mcp-adapter.md)；
- 冻结数据和控制模型上下文时读取[四份报告上下文与 Token 合同](../../references/report-context-efficiency.md)；
- 写两份创意报告的公共部分时读取[创意结构共同接口](../references/creative-structure-contract.md)；
- 冻结范围、核对案例和缺失时读取[取数与完整案例要求](references/data-requirements.md)；
- 提取、合并和拆分结构时读取[案例与结构归并规则](references/creative-rules.md)；
- 写报告时使用[报告模板](references/report-template.md)。

## 用户输入

用户只需明确要求生成、更新或修改外部视频创意报告。用户可以指定内部锚点周期、外部观察范围、平台、来源或已有报告；未指定时使用与外部需求报告相同的范围确定逻辑。只有多个范围同样合理或数据无法衔接时才询问。

正式业务取数优先使用当前 HTTP `onion-intelligence` MCP；只有用户明确提供冻结导出文件时才使用导出输入。不得由本 Skill 直连数据库、SSH或对象存储。

## 固定流程

1. 确定内部锚点周期、外部观察范围、平台、来源、视频边界、生成时间和冻结时刻，生成版本内报告 ID。
2. 使用共享冻结脚本或等价的单次程序化调用完成全部创意证据分页，外层对话只接收 manifest；从冻结快照核对稳定案例总数、来源构成、分页和缺失。
3. 冻结证据已能完整支持六维判断时直接形成案例输入；字段不足的候选、中心/边界案例和最终代表案例，再在一个程序化阶段批量取得开头、推进、转折、产品或证据怎样承接、结尾怎样行动及可定位画面或转写证据。详情返回写入私有运行快照，不逐案例进入外层上下文，也不默认回查全部228个案例。
4. 按共同六维语义提取结构观察；关键词、向量或模型只发现候选。每个隔离批次只输出`material_context_id`绑定的六维观察，所有完整案例必须且只能得到一个已处理去向，不能在批次输出中直接写报告。
5. 跨批归并只读取六维观察、中心案例、边界案例和必要来源元数据，不再次插入完整MCP证据。使用硬合并/拆分规则复核中心案例和边界案例；表面形式相似不能决定归并。
6. 至少2条独立完整案例支持同一关系时进入结构一览与详情；只有1条时进入“新增与单例案例”。
7. 按去重完整案例数从高到低排列，案例数相同时使用稳定语义键，再从`EC-001`起连续编号；填写共同定义表、适合/不能怎样使用、外部证据和2至3条代表案例。
8. 在不继承当前长对话的隔离模型上下文中，通过有界map/reduce输出结构映射或报告正文；后续计数、排序、编号、代表链接和格式使用确定性程序。按共同五段骨架生成报告，运行 `scripts/validate_report.py <报告>`；存在硬错误时不得称为完成。

## 完整性与边界

- 只分析可回源画面、画面顺序、可见动作、屏幕文字和转写文案；
- 真人/AI、UI真实性、语调、音色、声音感染力、互动量和效果数据不进入结构指纹；
- 真人口播、花字、快剪、学生做题、产品录屏等表面形式不能单独成为创意结构；
- 同一案例可以支持多个可定位结构，但在同一结构内只计一次；
- 外部互动或广告身份只作来源背景，不证明某结构有效；
- 分页中断、范围无法冻结、稳定案例总数无法守恒或关键画面/转写事实不足时停止或公开降级；
- 报告不生成口播、前贴、分镜、混剪或三个下游执行器。

## 下游 interface

第2、3部分必须符合共同接口。下游先读取结构一览筛候选，再读取候选卡和代表案例；记录“报告文件＋EC短编号＋实际参考素材”。

没有适配结构时允许下游原创。单例默认不参与筛选，只有用户明确选择时才能作为探索参考。

## 修改已有报告

只改表达时继承原范围、报告 ID 版本和结构成员；改归并时重算受影响结构；更新数据时重新冻结范围并生成新报告版本。不得覆盖旧文件。

## 完成标准

- 范围、稳定案例数和来源构成守恒；
- 所有可复用结构至少有2条独立案例；
- 共同定义表、EC连续编号、外部证据和代表案例格式通过校验；
- 创意结构一览中的每个`查看详情`都跳转到唯一EC详情锚点；
- 单例不进入下游默认候选；
- 结构关系能够被口播文案和 AI 前贴按共同 interface 筛选。
