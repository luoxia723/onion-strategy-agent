# 外部视频创意报告取数与完整案例要求

## 时间与范围

- 内部锚点周期：最近一个已经结束、有反馈数据的内部连续14天周期，或用户指定周期；
- 外部观察范围：默认从内部周期截止日次日开始，最多连续14天，且不得晚于冻结时刻；
- 与同轮外部需求报告使用同一范围确定逻辑，但两份报告独立生成；
- 媒体类型固定为视频，图片、图文、九宫格和落地页不作为降级输入；
- 保存生成时间、冻结时刻和报告 ID；冻结后新增或更新的数据不进入当前版本。

## 一张完整案例最少需要

- 稳定案例 ID、原视频身份和回源链接；
- 平台、来源类型：自然内容、教育广告或非教育广告；
- 观看/叙事关系；
- 开头画面、可见动作、屏幕文字和开头任务；
- 正文转写与画面的信息推进；
- 转折怎样发生；
- 产品或证明何时出现、承担什么任务；没有则明确无产品；
- 结尾画面、文案和怎样进入行动；
- 可定位的画面或转写证据；
- 数据完整度和异常。

这些事实既用于结构归并，也用于生成代表案例的`来源、开头、推进、产品/证明、结尾`五项摘要。

画面可用但没有转写时，可以只分析画面关系并公开缺口；转写可用但关键画面缺失时，只能分析文案推进，不能补造画面。

## 完整性

- 稳定案例 ID 去重后的完整案例数必须可核对；
- 同一视频从多条富化对象或查询路径返回时合并到同一案例；
- 某一来源缺失可以继续，但必须公开缺口；
- 分页中断、范围不明或唯一案例总数无法核对时停止正式生成；
- 完整案例保留在现有数据层或后续案例查询工具中；Skill 不生成全量机器台账。

## 报告所需统计

- 完整案例总数；
- 自然内容、教育广告、非教育广告各自的唯一案例数；
- 每个结构的去重完整案例数、来源构成和平台覆盖；
- 报告展示的代表案例数；
- 画面、转写、媒体或回源缺失的案例数量；
- 单例数量及其来源构成。
