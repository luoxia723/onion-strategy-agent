# 洋葱策略 Agent

> 当前是结构预览仓库：统一OAuth MCP及生成服务尚未部署完成，暂不可作为正式业务环境使用。

这是可直接作为Codex项目打开的 `strategy` 角色仓库。第一次打开时信任项目，并在Codex的MCP面板完成一次`onion-agent` OAuth连接；后续Git更新不需要重新登录。

更新方式：使用GitHub Desktop点击Pull，或在Codex里说“更新项目到最新”。更新流程只允许fast-forward，不影响`工作区/`和`.runtime/`中的既有文件。
